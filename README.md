# Праздничный дурдом 🎪

Сайт-календарь настоящих смешных, странных и локальных праздников: показывает, какой
необычный повод есть сегодня, и даёт поводы на любой другой день года.

## Как открыть

Никакой сборки и зависимостей нет — это обычные HTML/CSS/JS.

- Откройте `index.html` двойным кликом в браузере, **или**
- запустите локальный сервер из этой папки:

```bash
node tools/serve.mjs
# затем откройте http://127.0.0.1:5173
```

## Что внутри

| Файл | Что делает |
| --- | --- |
| `index.html` | каркас страницы |
| `styles.css` | оформление, адаптив, анимации |
| `app.js` | логика: выбор даты, календарь, поиск, избранное, конфетти |
| `data/holidays-*.js` | база праздников (434 записи) |
| `tools/check.mjs` | проверка базы: поля, даты, дубли, покрытие года |
| `tools/smoke.mjs` | смоук-тест рендера с заглушкой DOM |
| `tools/serve.mjs` | мини-сервер для локального просмотра |

## Возможности

- **Главная карточка дня** — праздник (или несколько) с описанием, идеями, как отметить, и фактом.
- **Навигация по датам** — стрелки, кнопка «сегодня», календарь на месяц, клавиши ← →.
- **Ссылка на день** — дата пишется в адрес (`#2026-11-07`), её можно отправить другу.
- **Поиск и категории** — по названию, городу, еде и описанию.
- **Избранное** — сохраняется в `localStorage`.
- **Случайный праздник** и **генератор повода** для дней без официальных дат.
- **«Плавающие» праздники** — Ла Томатина, День сурка-подобные и прочие правила
  («последняя среда августа», «второй вторник февраля») пересчитываются под текущий год.

## Как добавить праздник

Допишите объект в конец любого файла `data/holidays-*.js`:

```js
{ m: 11, d: 19, t: "Всемирный день туалета", e: "🚽", l: "Мир (ООН)", c: "fun",
  s: "Короткое описание в одну строку.",
  h: ["Первая идея", "Вторая идея"],
  f: "Любопытный факт." }
```

Для «плавающих» дат вместо `m`/`d` укажите правило:

```js
{ r: ["nth", 8, 5, 1], ... }   // первая пятница августа
{ r: ["last", 8, 3], ... }     // последняя среда августа
{ r: ["doy", 256], ... }       // 256-й день года
```

Категории: `fun`, `food`, `geek`, `nature`, `local`, `people`.

После правок проверьте базу:

```bash
node tools/check.mjs
node tools/smoke.mjs
```
